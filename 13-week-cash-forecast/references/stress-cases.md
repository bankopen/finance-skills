# Stress cases for 13-week-cash-forecast

Status: **DRAFT.** A methodology, not a statutory rule. The defaults are starting points; change them to fit your business, state the values you used, and label them **Hypothesis** in the output.

| Case | What changes | Default |
|---|---|---|
| Base | Receipts and payments as scheduled using the collection and payment patterns | none |
| Collections slip | Every receipt arrives later (receipts pushed beyond week 13 become Unscheduled) | +14 days |
| Largest customer pays late | The customer with the largest total open receivables pays later | +30 days |
| Payments cannot be deferred | Every payable is paid on its due date with no stretching. **Only different from the base if the base stretches payments** (for example a weekly run); if the base already pays on due date, say so and show it equal to the base | on due date |
| Combined | Collections slip and payments cannot be deferred | both |

Always show the first week below the minimum for each case, because two cases can share a low point and breach weeks apart.
