# Contributing

Thank you for helping. The most useful contributions are corrections to the rule references and real-world edge cases the skills mishandle.

1. Open an issue first for a new skill or a large change.
2. Follow [Writing a skill](docs/writing-a-skill.md). Run `node scripts/validate.mjs` before you open a pull request.
3. For a rule correction, cite the section and the notification or circular, and update the last-checked date. Do not add a rule without its source.
4. Never include real company, vendor, employee or customer data, account numbers, PAN, GSTIN or credentials in examples or issues. Use made-up data.
5. By contributing you agree your contribution is licensed under the MIT licence.

## Review
Changes to files under `references/` are reviewed against primary sources before merging. A reference file is marked VERIFIED only after a named reviewer confirms it.
